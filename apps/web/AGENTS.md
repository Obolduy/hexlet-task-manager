# apps/web/AGENTS.md

Дополняет корневой `AGENTS.md`. Действует только внутри `apps/web`.

## Стек

Vue 3 + Vite + TypeScript. Только Composition API и `<script setup>` —
Options API не использовать.

## Запреты

- Без роутера (vue-router).
- Без стора (Pinia, Vuex или любой другой).
- Без UI-библиотек и CSS-фреймворков — минимальный CSS, без дизайн-системы.

## Зависимости

Новые зависимости в `package.json` не добавлять без явного указания в
задаче. `vitest` и `@vue/test-utils` уже используются в проекте — дальше
действует общее правило.

## Типы

Источник правды для форм данных — `apps/api/src/schemas.py`. Не выдумывать
поля, которых там нет. При изменении `schemas.py` вручную обновлять
`apps/web/src/api/types.ts` — поля сверяются построчно с обоими файлами
открытыми рядом, отдельной таблицы соответствия нет.

## Слои

- К `api/` обращается только `TaskScreen.vue`.
- Остальные компоненты — без side-effects, получают данные через props.

## Тесты

- Команда: `npm run test` (из `apps/web`).
- У компонента с логикой (не чисто вёрстка) — минимум один тест.

## Размер

Если `.vue`-файл переваливает за ~80 строк — повод разбить на два
компонента, а не сигнал оставить как есть.
