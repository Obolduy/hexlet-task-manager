# apps/api/AGENTS.md

Дополняет корневой `AGENTS.md`. Действует только внутри `apps/api`.

## Стек

Python, FastAPI, SQLite через стандартный `sqlite3`, без ORM. Тесты — pytest
+ `TestClient` из FastAPI.

## Слои

- `routes/` — только HTTP: разбор запроса, вызов сервиса, сериализация
  ответа.
- `services/` — бизнес-логика и валидация, требующая обращения к данным.
- `models/` — SQL-запросы.

Известное и осознанное исключение — `routes/users.py` вызывает
`models/user.py` напрямую, сервисного модуля для пользователей нет. Это
самый старый эндпоинт проекта, оставлен как есть, **не предлагать
вынести в сервис** и не использовать как прецедент. Любой новый обход
сервисного слоя — в `routes/users.py` или где-либо ещё — нарушение
правила, а не продолжение уже принятого паттерна.

Ещё одно осознанное отступление — `services/task_service.py` называет
свой четвёртый метод `set_status`, а не `update_task_status` в общем
паттерне `<действие>_task[s]`. Переименовывать не нужно.

## Тесты

- Команда: `pytest apps/api/tests`.
- У нового эндпоинта минимум два теста: успешный сценарий и один сценарий
  с ошибкой (404/422).
- Тест, помеченный `skip`, не чинить и не удалять попутно с несвязанной
  задачей.

## Прочее

- Новые зависимости в `requirements.txt` не добавлять без явного указания в
  задаче.
